# Day 6 – Data Filtering

## Overview

This project is part of my Codomax Data Science Internship.

For Day 6, I used Python and Pandas to practice filtering, selecting, and sorting data from the cleaned dataset.

## Objectives

- Load the cleaned dataset.
- Select specific columns from the dataset.
- Filter records based on specific conditions.
- Filter records by product.
- Sort records based on values.
- Combine filtering and sorting operations.

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Dataset

The dataset used for this task is the cleaned e-commerce dataset from my previous Decode Labs project.

The dataset was loaded using Pandas from a CSV file.

## Data Filtering Operations

### Selecting Columns

Specific columns were selected for analysis, including Product, Quantity, UnitPrice, and TotalPrice.

### Filtering Records

Records were filtered using conditions such as quantity greater than a specified value and selecting specific products.

### Sorting Data

The dataset was sorted using the `sort_values()` function to organize records according to TotalPrice.

## Results

The dataset was successfully filtered, selected, and sorted using Pandas. These operations made it easier to identify specific records and prepare the data for further analysis.

## Conclusion

Day 6 provided practical experience with data filtering and manipulation using Pandas. The filtered dataset is ready for the data analysis tasks in Day 7.
